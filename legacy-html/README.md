# 智能钥匙柜管理系统 - 原始HTML版本

⚠️ **注意：此版本已停止维护，仅作为参考保留**

这是项目的原始HTML版本，包含了最初的设计和功能原型。

## 📁 文件说明

- `index.html` - 主页
- `borrow.html` - 借钥匙页面
- `return.html` - 还钥匙页面
- `script.js` - JavaScript功能
- `styles.css` - 样式文件

## 🔄 迁移说明

此版本的功能已经完全迁移到新的Vue3版本中：
- 所有页面布局和设计已迁移到 `../frontend/`
- 所有JavaScript功能已重构为Vue3组件
- 样式已适配Element Plus组件库

## 📖 使用说明

如需查看原始版本，可以直接在浏览器中打开 `index.html` 文件。

**推荐使用新版本：**
- 前端：`../frontend/`
